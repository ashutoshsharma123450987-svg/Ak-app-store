AK Apps Store – Admin

Yahan se apni app seedha website par upload karein. Yeh page sirf aapke liye hai.

🔐 Login (GitHub Token)

Is phone par yaad rakhein
Token kaise banayein?
  1. GitHub → Profile photo → Settings → Developer settings
  2. Personal access tokens → Fine-grained tokens → Generate new token
  3. Repository access: Only select repositories → Ak-app-store
  4. Permissions → Contents: Read and write
  5. Generate karke token copy karein aur yahan paste karein
Token kisi ko na dein. Yeh sirf aapke browser mein rehta hai.
